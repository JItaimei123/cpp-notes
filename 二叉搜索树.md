# 一.插入

```C++
struct Node {
    int key;
    Node* left;
    Node* right;
    Node(int k) : key(k), left(nullptr), right(nullptr) {}
};

class BST {
private:
    Node* root = nullptr;

public:
    bool insert(int _key) {
        if (root == nullptr) {
            root = new Node(_key);
            return true;
        }
        Node* cur = root;
        Node* parent = nullptr;
        while (cur) {
            parent = cur;
            if (_key < cur->key) cur = cur->left;
            else if (_key > cur->key) cur = cur->right;
            else return false;
        }
        if (_key < parent->key) parent->left = new Node(_key);
        else parent->right = new Node(_key);
        return true;
    }

    Node* insertRec(Node* root, int key) {
        if (root == nullptr) return new Node(key);
        if (key < root->key) root->left = insertRec(root->left, key);
        else if (key > root->key) root->right = insertRec(root->right, key);
        return root;
    }
};
```

## 拆开看

```C++
Node(int k) : key(k), left(nullptr), right(nullptr) {}
```

|部分|含义|
|-|-|
|`Node(int k)`|构造函数|
|`:`|初始化列表|
|`key(k)`|把 `key` 初始化为 `k`|
|`left(nullptr)`|把 `left` 初始化为 `nullptr`|

> `new` 的作用：分配内存 + 调用构造函数。C 的 `malloc` 只有分配内存。

        if (_key == cur->key) return true;
        else if (_key < cur->key) cur = cur->left;

# 三.删除

## 核心思路

1. 查找要删除的节点 N
2. 找不到 → 返回 false
3. 找到 → 根据孩子情况选择删除策略

## 四种情况

|情况|条件|操作|
|-|-|-|
|① 叶子节点|左右都空|父节点指针置空，删除 N|
|② 只有右孩子|左空，右不空|父节点指向 N 的右孩子|
|③ 只有左孩子|右空，左不空|父节点指向 N 的左孩子|
|④ 左右都不空|左右都不空|找右子树最小值替换，删除最小值节点|

## 树

```
        8
       / \
      3   10
     / \    \
    2   5    12
       / \   /
      4   6 11
```

## 四种情况演示

|删除|情况|操作|结果|
|-|-|-|-|
|删除 2|叶子|直接置空|3 的左孩子变空|
|删除 10|只有右孩子|12 替代 10|8 的右孩子变成 12|
|删除 12|只有左孩子|11 替代 12|10 的左孩子变成 11|
|删除 5|左右都有|找右子树最小值 6 替换|5 变 6，原来 6 被删|

## 代码框架

```C++
bool erase(int _key) {
    Node* cur = root;
    Node* parent = nullptr;

    while (cur) {
        if (_key < cur->key) { parent = cur; cur = cur->left; }
        else if (_key > cur->key) { parent = cur; cur = cur->right; }
        else break;
    }
    if (cur == nullptr) return false;

    // 情况 ② + ③：只有一个孩子
    if (cur->left == nullptr) {
        if (cur == root) root = cur->right;
        else if (parent->left == cur) parent->left = cur->right;
        else parent->right = cur->right;
    }
    else if (cur->right == nullptr) {
        if (cur == root) root = cur->left;
        else if (parent->left == cur) parent->left = cur->left;
        else parent->right = cur->left;
    }
    else {
        // 情况 ④：左右都有孩子 → 找右子树最小值
        Node* minParent = cur;
        Node* minNode = cur->right;
        while (minNode->left) {
            minParent = minNode;
            minNode = minNode->left;
        }
        cur->key = minNode->key;
        if (minParent->left == minNode)
            minParent->left = minNode->right;
        else
            minParent->right = minNode->right;
        delete minNode;
        return true;
    }
    delete cur;
    return true;
}
```
